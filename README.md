# 聚星路現場板｜A／B 區人流與交通實況

天水圍**聚星路**互動 Web App：CocoPi **A區／B區**雙訊號燈 ＋ 共用圖表 ＋ 運輸署公開資料幹道地圖。

**Live:** https://danielshtong.github.io/tin-shui-wai-traffic/

## 人流訊號（每區獨立）
| 等級 | 條件 |
|------|------|
| 🟢 綠（安全／正常） | ≤ 5 人 |
| 🔴 紅（人數偏高・請注意） | ＞ 5 人 |

| 區 | API | 欄位 |
|----|-----|------|
| **A區** | `…/eventAPIKey/efee43b4132b83b082d15dd9cd3c7f83` | **`no_of_face`** |
| **B區** | `…/eventAPIKey/4e1ce54a77a08bf54547811707e06468` | **`no_of_face_B`**（後備 `no_of_face`／`count`） |

兩區 **每 60 秒同步**輪詢；圖表雙線（A／B）＋門檻 y=5。

## 雙條件升級
**任一區人數＞5** 且 **附近探測器黃／紅** → 顯示「**建議通知執法**」。
