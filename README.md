# 聚星路現場板｜A／B／C 區人流與交通實況

天水圍**聚星路**互動 Web App：CocoPi **三區**人數 ＋ **綜合訊號燈** ＋ 運輸署公開資料幹道地圖。

**Live:** https://danielshtong.github.io/tin-shui-wai-traffic/
